# EduBot Frontend 🎨

Antarmuka pengguna modern untuk EduBot AI Chatbot yang dibangun dengan React.

## Teknologi
- React.js & Vite
- Tailwind CSS (Styling)
- Framer Motion (Animations)
- Lucide React (Icons)
- React Markdown (Formatting)

## Fitur UI
- Sidebar untuk pengaturan parameter mengajar.
- Chat window dengan auto-scroll dan typing indicator.
- Penyimpanan sesi di localStorage.

## Cara Menjalankan
1. `npm install`
2. `npm run dev`
